# ComfyUI-DJ_ImageExpand（图像扩展编辑器）

> **版本** `261008-005223` · **作者** 大江 · **平台** ComfyUI
> **依赖** 无特殊依赖（Python ≥ 3.10）

## 一、功能概述

给 ComfyUI 的图像扩图（outpaint）流程做的一个可视化编辑节点：加载图片后，直接在节点面板上旋转、裁切、加填充边，所见即所得地做出扩图底图。新增的填充区域会同步输出到蒙版，模型只画蒙版标白的部分；还可以一键把结果缩放到指定百万像素预算，适配不同模型的尺寸要求。

## 二、功能说明

### 2.1 节点与输出

| 项 | 值 |
|---|---|
| 节点名 / 注册 ID | `ComfyUI-DJ_ImageExpand`（显示名带「图像扩展编辑器」后缀） |
| 分组 | `DJ/ImageExpand` |

| 输出槽 | 内容 |
|---|---|
| 图像 | 变换后的图像批次 |
| 蒙版 | 白色 = 模型需要绘制的区域（填充边距、旋转空角、图片透明部分） |
| 缝合器 | 全画布缝合器，接 Stitch Inpaint 节点可在扩图结果上恢复保留的源图像素 |
| 原图 | 变换前的原图（透明部分显示为白色） |
| 宽度 / 高度 | 输出尺寸（INT） |
| 提示图 | 透明部分显示为白底的图像，接写提示词节点用；无透明部分时与「图像」相同 |

### 2.2 变换参数（面板上直接拖 / 填）

| 参数 | 说明 / 默认值 |
|---|---|
| 旋转角度 | -180 ~ 180°，步进 0.1，默认 0；先旋转再裁切填充 |
| 裁剪比例 | free / source / 1:1 / 9:16 / 16:9 / 2:3 / 3:2 / 3:4 / 4:3 / 9:21 / 21:9，默认 free；可放 `djimageexpand_presets.json` 自定义 |
| 裁剪框 x / y / 宽 / 高 | 像素值，宽高填 0 = 保留全部 |
| 填充边 左/上/右/下 | 0 ~ 32768 px，默认 0；落在输出蒙版里 |
| 羽化 | 0 ~ 4096 px，默认 24；蒙版向保留像素过渡，图像本身保持硬边 |
| 整除倍数 | 1 ~ 4096，默认 1（关）；右/下补几 px 填充让宽高整除，适配需要 8/16/32 尺寸的模型 |
| 填充色 | 默认 `#00ff00` 纯绿；支持 #RGB/#RRGGBB、R,G,B、灰度值、CSS 颜色名 |

### 2.3 缩放预算（可选）

| 参数 | 说明 / 默认值 |
|---|---|
| Resize 开关 | 默认关 |
| Megapixels | 0.01 ~ 16 MP，默认 1.0；保持宽高比缩放到该像素预算 |
| Step | 1 ~ 256 px，默认 1；每边独立取整到该倍数（VAE 友好常用 8 / 32 / 64） |
| 方法 | lanczos（默认）/ area / bicubic / bilinear / nearest-exact |

### 2.4 缝合参数（可选）

| 参数 | 说明 / 默认值 |
|---|---|
| stitch_blend | 0 ~ 512 px，默认 32；缝合器贴回时的过渡带宽度 |
| stitch_grow | -256 ~ 256 px，默认 0；正 = 生成结果多覆盖一条源图，负 = 多保留源图 |

### 2.5 面板交互

- 节点面板内嵌预览舞台：青色方形手柄拖裁剪框，橙色菱形/四角手柄拖填充边和画布大小，按住图片拖动可移动裁切位置（整图无裁切时图片在填充里滑动）
- 比例芯片行：点选比例一键裁切/填充到该形状；锁形按钮可在拖手柄时保持画布形状
- 「打开编辑器」进全屏编辑模式：滚轮缩放、中键/Alt 拖动平移、绿色旋钮旋转（Shift 吸附 15°）
- 齿轮设置：在图上显示蒙版（默认开，青色覆盖模型需绘制的区域）

### 安装铁律（本地插件专用，不可违反）

- **本地手搓插件一律用 `link:` 指向源码目录，绝不打包成 `.tgz`、绝不用 `file:xxx.tgz`。**
- 为什么：插件就放在 `<profile>\plugins\` 里，改完代码重启 DSH 就生效；pnpm 在这里只干一件事——在 node_modules 里放一个"快捷方式"（junction）指向源码目录。一旦写成 `file:xxx.tgz`，pnpm 会把 tgz 当"安装包"，每次 install 都从旧包解包覆盖，你改好的代码会被反复还原成旧版本；本地插件不上传、不分发，打 tgz 包纯属自找麻烦。

## 四、注意事项 / 已知边界

- 图片只能来自 ComfyUI 的 input 文件夹（上传或服务器文件），不能读外部路径
- 填充边单侧上限 32768 px；裁剪框最小 8×8 px
- 缩放时宽高各自取整到 Step，可能产生轻微拉伸（>1% 时面板会提示）
- 只改前端 JS 时 `Ctrl+F5` 刷新页面即可生效；改了 `.py` 需要重启 ComfyUI
